# CAN-Sentinel — Member 4 Dashboard

A local PyQt5 dashboard for demonstrating CAN traffic monitoring and intrusion-alert handling.

## Dashboard features

- Start and stop simulated CAN message generation.
- View traffic with timestamp, CAN ID, payload, and NORMAL/SUSPICIOUS status.
- Filter stored traffic by CAN ID and status; the table shows up to the latest 200 matching messages.
- Review a separate alert history with severity and reason fields, plus severity/reason filters.
- Export the currently filtered traffic or alert history to CSV.
- Clear the visible traffic table without deleting the stored records used for CSV export.
- Clear all in-memory session records only after a confirmation prompt.

## Requirements

- Python 3.10 or newer recommended.
- PyQt5 (installed from `requirements.txt`).
- Windows, Linux, or another supported desktop environment for Qt.

## Fresh setup (Windows PowerShell)

Run these commands from the repository root, where `dashboard.py` and `requirements.txt` are located:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python dashboard.py
```

If PowerShell blocks activation, you can use Command Prompt instead:

```bat
py -m venv .venv
.venv\Scripts\activate.bat
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python dashboard.py
```

## Run integration tests

With the virtual environment activated and dependencies installed:

```powershell
python -m unittest discover -s tests -v
```

For headless test runs where a Qt display is not available, set the offscreen platform before running tests:

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
python -m unittest discover -s tests -v
```

## Git hygiene and branch readiness

- Keep this contribution on `member-4-testing`; do not commit this work to `main` directly.
- `.gitignore` excludes Python caches, virtual environments, test artifacts, local environment files, and common IDE/OS files.
- Do not commit `.venv/`, credentials, local data, or generated CSV exports.
- Before pushing, inspect `git status --short`, `git diff --check`, and `git diff --stat`.

## Limitations

This version is a demonstration UI. CAN frames are generated by local simulation logic, and the demo marks every seventh generated message as suspicious. The alert severity/reason are rule-based demo values, not results from a trained machine-learning model. The dashboard is not connected to a real vehicle or live SocketCAN sniffer. Traffic and alert history remain in memory only for the current application session; export CSV files to retain them after closing the app.
